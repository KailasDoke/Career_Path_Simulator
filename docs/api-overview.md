# API Overview

This document provides a high-level overview of the future REST API endpoints for the Career Path Simulator.

## Base URL
`/api/v1`

## Future Endpoints (To be implemented)

*   **Users/Students**: `/users`, `/profiles`
*   **Pathways**: `/pathways`, `/pathways/simulate`
*   **Institutions**: `/institutions`
*   **Scholarships**: `/scholarships`
*   **Loans**: `/loans`

*Detailed API specifications (e.g., OpenAPI/Swagger) will be added in subsequent phases.*
